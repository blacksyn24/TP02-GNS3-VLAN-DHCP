# -CCNA2-VLANs-Router-on-a-Stick-STP-DHCPv4-AgroExport-B-nin
TP GNS3 : segmentation réseau d'AgroExport Bénin en 2 VLANs (Administration, Logistique) via switch IOSvL2. Routage inter-VLAN en Router-on-a-Stick sur c7200 avec trunk 802.1Q. Attribution IP automatique via 2 pools DHCPv4. Spanning Tree Rapid PVST+ activé pour la stabilité. Progression CCNA vers DHCPv6.
